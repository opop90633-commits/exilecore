計算器

配天賦、裝備、技能，右邊會算出每秒傷害與防禦

技能與輔助寶石

點技能名稱改等級與輔助寶石；裡面會列出每一顆輔助掛上去大約多幾 % 傷害。光環要綁在按鍵上才會開。

規劃

點節點：配到那裡（自動走最短的路）。點已配的節點：退掉（連帶退掉因此斷線的）。
屬性點（+5 任一屬性）配了之後有顏色：紅＝力量、綠＝敏捷、藍＝智慧； 點已配的屬性點可以改屬性或退掉。沒選的照職業的主屬性，選好的會跟著代碼帶進遊戲。
六角形是珠寶孔：配了之後在遊戲裡把珠寶放進去（這裡只能規劃孔位）。 滑到珠寶孔會畫出遺時星晶的範圍（基本 2 格、「更大」3 格、「巨大」4 格），並列出範圍裡有幾個小點、核心。
複製代碼後，遊戲裡打 /tree import 貼上，或在天賦總覽按「匯入規劃代碼」。

珠寶孔的範圍

遺時星晶放在珠寶孔裡，範圍內已配置的每個小點都多給一次它的詞綴。
